# Tech Context

## Stack

- Next.js（App Router / RSC / Turbopack）
- React 19
- TypeScript
- NextAuth + Google OAuth2
- Turso（LibSQL）
- MUI
- Vitest / Playwright
- pnpm

## Local Dev

- 環境変数: .env.example を .env.local にコピーして設定
- 起動: `pnpm dev`
- テスト: `pnpm test:updates` / `pnpm test:playwright`
- ビルド: `pnpm build`
